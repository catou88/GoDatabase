# Security Policy

## Supported Versions

The project currently supports the latest main branch and the most recent release line. Older or experimental builds are not guaranteed to receive security fixes.

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in public GitHub issues.

Instead, report the issue privately by emailing the maintainer or by using the repository's private security reporting mechanism if one is configured.

When reporting, include:
- a description of the issue
- affected version or commit
- steps to reproduce the problem
- the impact and risk level
- any suggested mitigation or fix

We will acknowledge receipt within 5 business days and will work toward a fix as quickly as possible.

## Response Expectations

We aim to:
- triage reported issues promptly
- assess impact and severity
- release a fix or mitigation when appropriate
- communicate clearly with the reporter throughout the process

We appreciate responsible disclosure and will work with reporters to address security issues in a timely and professional manner.
